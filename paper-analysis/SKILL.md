# 論文分析

當使用者上傳論文，或查資料的結果包含論文時，根據論文內容主動提供以下分析。若使用者另有指定問題或格式，以使用者要求為優先。

## 分析重點

1. **這篇在做什麼**：用直白語言說明研究目標、研究對象與核心貢獻。
2. **解決什麼問題**：交代既有方法的限制、研究缺口，以及這個問題為何重要。
3. **如何解決**：拆解核心想法、模型或實驗設計、關鍵假設、資料、評估方式與主要結果。
4. **物理意義**：解釋公式、變數、尺度、機制與結果在真實系統中的意涵；不要只重述數學。若不是物理領域，改為說明該領域的機制、直覺或實際意義。
5. **流程是什麼**：按「輸入／初始條件 → 方法或裝置 → 計算／實驗步驟 → 輸出 → 驗證 → 結論」整理完整流程；可用簡潔編號或箭頭表示。

## 回答原則

- 先給一段不需專業背景也能理解的總結，再補必要技術細節。
- 對重要術語、公式與圖表說明「它代表什麼」及「為什麼需要它」。
- 清楚區分論文明確寫出的內容、合理推論與尚未證實的解讀。
- 優先標示頁碼、章節、圖、表或公式編號，讓使用者能回到原文核對。
- 說明主要結果是否真的支持作者的主張，並指出關鍵限制、適用範圍或可能失效的條件。
- 若只能取得摘要或部分內容，明確說明分析範圍，不把缺失細節當成已知事實。
- 預設使用繁體中文；公式與專有名詞可保留原文，並附中文解釋。
